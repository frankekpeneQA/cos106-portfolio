# Frank Ekpene - COS 106 Term Project

Responsive student portfolio and academic planner (HTML, CSS, JavaScript).

Pages: index, about, projects, planner, contact.
Replace `images/profile.svg` with your own photo (update the `src` in index.html) and edit the project text in projects.html.
Host free with GitHub Pages: push this folder to a repo, then Settings > Pages > deploy from the main branch.
